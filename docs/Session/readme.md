# Session

| Endpoint | Description |
|---|---|
| [GET Player Session](GET%20Player%20Session.md) | Get the current session state of a player. `loopState` indicates what the player is currently doing — `MENUS` means they are in the main menu, `PREGAME` means they are in agent select, `INGAME` means they are in a match. When `loopState` is `PREGAME` or `INGAME`, `loopStateMetadata` contains the match ID that can be used with the [GET Pre-Game Match](pre-game-match) or [GET Current Game Match](current-game-match) endpoints. |
