# POST Activity Lookup

> View on the website: <https://valdocs.prometheuz.me/endpoint/activity-lookup>

Look up the activity ID of a party. The activity ID is required for the join link endpoints, such as the [POST Shared Join Link](https://valdocs.prometheuz.me/endpoint/shared-join-link) and [DELETE Disable Join Link](https://valdocs.prometheuz.me/endpoint/disable-join-link) endpoints.

Method: `POST`  
URL: `https://{cluster}.pp.sgp.pvp.net/activities/v1/lookup`  

## Headers

- `Authorization: Bearer {auth token}`

## Variables

- `{cluster}`: SGP region cluster, e.g. `euc-prod` for EU
- `{auth token}`: Obtained with the [Entitlements Token](https://valdocs.prometheuz.me/endpoint/entitlements-token) endpoint or Riot auth

## Example Request

```sh
curl -X POST 'https://{cluster}.pp.sgp.pvp.net/activities/v1/lookup' \
  -H 'Authorization: Bearer {auth token}' \
  -H 'Content-Type: application/json' \
  --data '{body}'
```

## Body

```ts
type ActivityLookupBody = {
    product: "valorant";
    /** The ID of the party to look up the activity for */
    party: string;
};
```

## Response

```ts
type ActivityLookupResponse = {
    /** Activity ID */
    activityId: string;
};
```
