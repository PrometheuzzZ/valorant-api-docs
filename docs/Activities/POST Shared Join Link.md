# POST Shared Join Link

> View on the website: <https://valdocs.prometheuz.me/endpoint/shared-join-link>

Create a shared join link for an activity. The request has an empty body.

The returned join code can be shared with other players, either directly or through the `smartUrl`, to let them join the party. The link can be revoked with the [DELETE Disable Join Link](https://valdocs.prometheuz.me/endpoint/disable-join-link) endpoint.

Method: `POST`  
URL: `https://{cluster}.pp.sgp.pvp.net/activities/v1/{activity id}/join-codes/shared`  

## Headers

- `Authorization: Bearer {auth token}`

## Variables

- `{cluster}`: SGP region cluster, e.g. `euc-prod` for EU
- `{activity id}`: The ID of the activity, obtained from the [POST Activity Lookup](https://valdocs.prometheuz.me/endpoint/activity-lookup) endpoint
- `{auth token}`: Obtained with the [Entitlements Token](https://valdocs.prometheuz.me/endpoint/entitlements-token) endpoint or Riot auth

## Example Request

```sh
curl -X POST 'https://{cluster}.pp.sgp.pvp.net/activities/v1/{activity id}/join-codes/shared' \
  -H 'Authorization: Bearer {auth token}'
```

## Response

```ts
type SharedJoinLinkResponse = {
    /** The join code, e.g. `0000-0000-0000` */
    joinCode: string;
    /** Link containing the join code, e.g. `https://gg.riotgames.com/VAL?joinCode=0000-0000-0000` */
    smartUrl: string;
    /** Expiration date of the join code in ISO 8601 format */
    expiresAt: string;
    /** Whether the join code is currently active */
    isActive: boolean;
};
```
