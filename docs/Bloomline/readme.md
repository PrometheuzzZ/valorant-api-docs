# Bloomline

| Endpoint | Description |
|---|---|
| [GET Bloomline Player](GET%20Bloomline%20Player.md) | Get the player's Bloomline (agent progression) for every agent. Each entry of `Bonsais` is one agent, the `BonsaiID` being the agent UUID. |
| [GET Bloomline Player Bonsai](GET%20Bloomline%20Player%20Bonsai.md) | Get the player's Bloomline for a single agent. Unlike [GET Bloomline Player], the bonsai includes its `NumberModules` (the agent stats). |
| [POST Update Bloomline Player Bonsai](POST%20Update%20Bloomline%20Player%20Bonsai.md) | Set the hype, background, clip, border and number modules shown for an agent. IDs in the body are written as 32 uppercase hex digits without dashes, and `00000000000000000000000000000000` clears a slot. |
| [GET Bloomline Valid Queues](GET%20Bloomline%20Valid%20Queues.md) | Get the queues whose matches count towards Bloomline progression, and the queues that track a performance score. |
