# GET Party Player

> View on the website: <https://valdocs.prometheuz.me/endpoint/party-player>

Get the party information for the given player

Method: `GET`  
URL: `https://glz-{region}-1.{shard}.a.pvp.net/parties/v1/players/{puuid}`  
Internal name: `Party_FetchPlayer`  

## Headers

- `X-Riot-ClientPlatform: {client platform}`
- `X-Riot-ClientVersion: {client version}`
- `X-Riot-Entitlements-JWT: {entitlement token}`
- `Authorization: Bearer {auth token}`

## Variables

- `{region}`: The region of the account: `na`, `latam`, `br`, `eu`, `ap` or `kr`
- `{shard}`: The shard the account was created on: `na`, `pbe`, `eu`, `ap` or `kr`
- `{puuid}`: A player's UUID
- `{client platform}`: See [Client Platform](https://valdocs.prometheuz.me/endpoint/player-mmr#client-platform)
- `{client version}`: See [Client Version](https://valdocs.prometheuz.me/endpoint/player-mmr#client-version)
- `{entitlement token}`: Obtained with the [Entitlements Token](https://valdocs.prometheuz.me/endpoint/entitlements-token) or [Entitlement](https://valdocs.prometheuz.me/endpoint/entitlement) endpoint
- `{auth token}`: Obtained with the [Entitlements Token](https://valdocs.prometheuz.me/endpoint/entitlements-token) endpoint or Riot auth
