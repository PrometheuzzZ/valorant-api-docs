# GET Player Goldstars

> View on the website: <https://valdocs.prometheuz.me/endpoint/player-goldstars>

Get the goldstars ("medals") of a player: how often each goldstar was earned per act, the best value per act, and a breakdown of recent matches.

Works for other players' PUUIDs as well. The values change after every match, so only cache them briefly.

The response keys are obfuscated and have changed between response versions (31 and 32 have been observed): in version 31 kills, assists and plants were sent per round, in version 32 as the match total. To determine the unit of a goldstar, divide the real match total by the goldstar value - a result of about 1 means the goldstar is the match total, a result close to the number of rounds means it is a per-round value. Values are float32, so numbers like `24.000001` are normal and should be rounded for display.

The season ID `00000000-0000-0000-0000-000000000000` in `tempS` is not a real act but the all-time summary. The `id` of a match is always an empty string, so the only link to the match history is the start time in `tempG` - matching a match from the history with the closest entry in `tempM` within about ten minutes works in practice.

The meaning of the goldstar IDs is listed in the [GET Goldstars](https://valdocs.prometheuz.me/endpoint/goldstars) endpoint.

For a player without any goldstars, `tempS` and `tempM` are empty. Matches in which no player earned a goldstar exist as well, in which case `tempP` is an empty object.

Method: `GET`  
URL: `https://pd.{shard}.a.pvp.net/goldstars/v1/players/{puuid}`  

## Headers

- `X-Riot-ClientPlatform: {client platform}`
- `X-Riot-ClientVersion: {client version}`
- `X-Riot-Entitlements-JWT: {entitlement token}`
- `Authorization: Bearer {auth token}`

## Variables

- `{shard}`: The shard the account was created on: `na`, `pbe`, `eu`, `ap` or `kr`
- `{puuid}`: A player's UUID
- `{client platform}`: See [Client Platform](https://valdocs.prometheuz.me/endpoint/player-mmr#client-platform)
- `{client version}`: See [Client Version](https://valdocs.prometheuz.me/endpoint/player-mmr#client-version)
- `{entitlement token}`: Obtained with the [Entitlements Token](https://valdocs.prometheuz.me/endpoint/entitlements-token) or [Entitlement](https://valdocs.prometheuz.me/endpoint/entitlement) endpoint
- `{auth token}`: Obtained with the [Entitlements Token](https://valdocs.prometheuz.me/endpoint/entitlements-token) endpoint or Riot auth

## Example Request

```sh
curl -X GET 'https://pd.{shard}.a.pvp.net/goldstars/v1/players/{puuid}' \
  -H 'X-Riot-ClientPlatform: {client platform}' \
  -H 'X-Riot-ClientVersion: {client version}' \
  -H 'X-Riot-Entitlements-JWT: {entitlement token}' \
  -H 'Authorization: Bearer {auth token}'
```

## Response

```ts
type PlayerGoldstarsResponse = {
    /** Player UUID */
    puuid: string;
    /** Version of the response format, 31 and 32 have been observed */
    version: number;
    /** Act ID to the summary of that act. The all-zero ID is the all-time summary instead of a real act */
    tempS: {
        [x: string]: {
            /** Duplicate of the act ID */
            tempS: string;
            /** Goldstar ID to the summary of that goldstar for the act */
            tempA: {
                [x: string]: {
                    /** Goldstar ID */
                    id: string;
                    /** How often the goldstar was earned during the act */
                    tempC: number;
                    /** Best value of the goldstar during the act */
                    tempB: number;
                };
            };
        };
    };
    /** Recent matches with goldstars */
    tempM: {
        /** Always an empty string - the match ID is not returned */
        id: string;
        /** Start time of the match in milliseconds since epoch */
        tempG: number;
        /** Player UUID to the goldstars of that player in this match. Contains all participants, not just the requested player */
        tempP: {
            [x: string]: {
                /** Goldstar ID to the value of that goldstar in this match */
                tempA: {
                    [x: string]: {
                        /** Goldstar ID */
                        id: string;
                        /** Value of the goldstar in this match */
                        tempV: number;
                        /** Whether the value is a record for the act */
                        tempB: boolean;
                    };
                };
            };
        };
    }[];
};
```
