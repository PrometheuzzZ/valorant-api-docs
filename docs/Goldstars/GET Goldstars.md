# GET Goldstars

> View on the website: <https://valdocs.prometheuz.me/endpoint/goldstars>

Get the list of all existing goldstars ("medals"), the awards shown after a match for stats such as kills, assists or headshot percentage.

The list does not depend on the player and rarely changes, so it can be cached for a long time. Riot does not return localized names or descriptions - the only name is the internal one in the obfuscated `tempT` field, which has also been observed under the keys `displayName`, `name`, `title` and `devName` in different client builds.

The internal names in the `tempT` field identify every goldstar, including the three that could previously only be guessed from the data. The meaning column below was confirmed by comparing the values of the [GET Player Goldstars](https://valdocs.prometheuz.me/endpoint/player-goldstars) endpoint with the stats of the same matches from the [GET Match Details](https://valdocs.prometheuz.me/endpoint/match-details) endpoint:

The `MVP`, `Distinction` and `Trades` values could not be reproduced from the data of the [GET Match Details](https://valdocs.prometheuz.me/endpoint/match-details) endpoint and are likely server-side stats that are not part of the match details. Any other ID returned by this endpoint is unknown - use its `tempT` internal name as a hint. Note that the units of the identified goldstars are not fixed either, see the [GET Player Goldstars](https://valdocs.prometheuz.me/endpoint/player-goldstars) endpoint for how to determine them.

Method: `GET`  
URL: `https://pd.{shard}.a.pvp.net/goldstars/v1/goldstars`  

## Headers

- `X-Riot-ClientPlatform: {client platform}`
- `X-Riot-ClientVersion: {client version}`
- `X-Riot-Entitlements-JWT: {entitlement token}`
- `Authorization: Bearer {auth token}`

## Variables

- `{shard}`: The shard the account was created on: `na`, `pbe`, `eu`, `ap` or `kr`
- `{client platform}`: See [Client Platform](https://valdocs.prometheuz.me/endpoint/player-mmr#client-platform)
- `{client version}`: See [Client Version](https://valdocs.prometheuz.me/endpoint/player-mmr#client-version)
- `{entitlement token}`: Obtained with the [Entitlements Token](https://valdocs.prometheuz.me/endpoint/entitlements-token) or [Entitlement](https://valdocs.prometheuz.me/endpoint/entitlement) endpoint
- `{auth token}`: Obtained with the [Entitlements Token](https://valdocs.prometheuz.me/endpoint/entitlements-token) endpoint or Riot auth

## Example Request

```sh
curl -X GET 'https://pd.{shard}.a.pvp.net/goldstars/v1/goldstars' \
  -H 'X-Riot-ClientPlatform: {client platform}' \
  -H 'X-Riot-ClientVersion: {client version}' \
  -H 'X-Riot-Entitlements-JWT: {entitlement token}' \
  -H 'Authorization: Bearer {auth token}'
```
