# POST Send Chat

> View on the website: <https://valdocs.prometheuz.me/endpoint/send-chat>

Send a message to the specified group

Method: `POST`  
URL: `https://127.0.0.1:{port}/chat/v6/messages`  

## Headers

- `Authorization: Basic {base64 encoded "riot:{lockfile password}"}`

## Variables

- `{port}`: The port from the Riot Client lockfile (`%LocalAppData%\Riot Games\Riot Client\Config\lockfile`)
- `{base64 encoded "riot:{lockfile password}`

## Example Request

```sh
curl -X POST 'https://127.0.0.1:{port}/chat/v6/messages' \
  -k \
  -u 'riot:{lockfile password}' \
  -H 'Content-Type: application/json' \
  --data '{body}'
```

## Body

```ts
type SendChatBody = {
    /** The conversation ID of the group to send the message to */
    cid: string;
    message: string;
    /** Use `chat` for whispers, `groupchat` for group messages, and `system` for system messages */
    type: "groupchat" | "chat" | "system";
};
```
