# GET Chat Participants

> View on the website: <https://valdocs.prometheuz.me/endpoint/chat-participants>

Get information about the participants of all active conversations or a specific conversation if a cid is provided

Method: `GET`  
URL: `https://127.0.0.1:{port}/chat/v5/participants`  

## Headers

- `Authorization: Basic {base64 encoded "riot:{lockfile password}"}`

## Variables

- `{port}`: The port from the Riot Client lockfile (`%LocalAppData%\Riot Games\Riot Client\Config\lockfile`)
- `{base64 encoded "riot:{lockfile password}`

## Query Parameters

- `cid` (optional)

## Example Request

```sh
curl -X GET 'https://127.0.0.1:{port}/chat/v5/participants?cid={cid}' \
  -k \
  -u 'riot:{lockfile password}'
```

## Response

```ts
type ChatParticipantsResponse = {
```
