# GET Current Game Chat Info

> View on the website: <https://valdocs.prometheuz.me/endpoint/current-game-chat-info>

Get information about the current game chat

Method: `GET`  
URL: `https://127.0.0.1:{port}/chat/v6/conversations/ares-coregame`  

## Headers

- `Authorization: Basic {base64 encoded "riot:{lockfile password}"}`

## Variables

- `{port}`: The port from the Riot Client lockfile (`%LocalAppData%\Riot Games\Riot Client\Config\lockfile`)
- `{base64 encoded "riot:{lockfile password}`

## Example Request

```sh
curl -X GET 'https://127.0.0.1:{port}/chat/v6/conversations/ares-coregame' \
  -k \
  -u 'riot:{lockfile password}'
```
