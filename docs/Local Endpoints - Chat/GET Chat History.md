# GET Chat History

> View on the website: <https://valdocs.prometheuz.me/endpoint/chat-history>

Get chat history for all conversations or a specific conversation if the cid is provided

Method: `GET`  
URL: `https://127.0.0.1:{port}/chat/v6/messages`  

## Headers

- `Authorization: Basic {base64 encoded "riot:{lockfile password}"}`

## Variables

- `{port}`: The port from the Riot Client lockfile (`%LocalAppData%\Riot Games\Riot Client\Config\lockfile`)
- `{base64 encoded "riot:{lockfile password}`

## Query Parameters

- `cid` (optional)

## Example Request

```sh
curl -X GET 'https://127.0.0.1:{port}/chat/v6/messages?cid={cid}' \
  -k \
  -u 'riot:{lockfile password}'
```
