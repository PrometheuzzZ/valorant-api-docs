# Store

| Endpoint | Description |
|---|---|
| [POST Storefront](POST%20Storefront.md) | Get the currently available items in the store |
| [POST Create Order](POST%20Create%20Order.md) | Create an in-game purchase order. The `OfferID` can be obtained from the [POST Storefront](storefront) endpoint. |
| [GET Get Order](GET%20Get%20Order.md) | Get the status and rewards of a purchase order. The `{order id}` can be obtained from the [POST Create Order](create-order) endpoint. |
| [GET Wallet](GET%20Wallet.md) | Get the current wallet balance for the user |
| [GET Owned Items](GET%20Owned%20Items.md) | List what the player owns (agents, skins, buddies, ect.) |
| [GET All Owned Items](GET%20All%20Owned%20Items.md) | List everything the player owns across every item type. This is the [GET Owned Items] endpoint without an item type, so the response contains one `EntitlementsByTypes` entry per item type the player owns items of. |
| [GET Gift Purchaser Eligibility](GET%20Gift%20Purchaser%20Eligibility.md) | Check whether a player is eligible to send gifts to others. |
| [POST Gift Recipient Eligibility](POST%20Gift%20Recipient%20Eligibility.md) | Check whether a specific recipient player is eligible to receive a gift from the purchaser. |
| [GET Agent Storefront](GET%20Agent%20Storefront.md) | Get the agent store, listing all purchasable agents with their available offers and costs. |
