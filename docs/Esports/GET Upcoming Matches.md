# GET Upcoming Matches

> View on the website: <https://valdocs.prometheuz.me/endpoint/upcoming-matches>

Get upcoming esports matches for VCT leagues. Returns leagues, tournaments, and teams data.

Method: `GET`  
URL: `https://pd.{shard}.a.pvp.net/esports-service/v2/upcomingMatches`  
Internal name: `Esports_GetUpcomingMatches`  

## Headers

- `X-Riot-Entitlements-JWT: {entitlement token}`
- `Authorization: Bearer {auth token}`

## Variables

- `{shard}`: The shard the account was created on: `na`, `pbe`, `eu`, `ap` or `kr`
- `{entitlement token}`: Obtained with the [Entitlements Token](https://valdocs.prometheuz.me/endpoint/entitlements-token) or [Entitlement](https://valdocs.prometheuz.me/endpoint/entitlement) endpoint
- `{auth token}`: Obtained with the [Entitlements Token](https://valdocs.prometheuz.me/endpoint/entitlements-token) endpoint or Riot auth

## Query Parameters

- `leagueID` (required): Comma-separated list of league IDs. Default VCT leagues: 107254585505459304,109940824119741550,109974795266458277,106109559530232966,109974804058058602,111691194187846945,109222784797127274
- `locale` (optional): Locale for localized names, e.g. "ru-RU", "en-US"
- `sport` (optional): Sport identifier, always "val" for Valorant

## Example Request

```sh
curl -X GET 'https://pd.{shard}.a.pvp.net/esports-service/v2/upcomingMatches?leagueID={leagueID}&locale={locale}&sport={sport}' \
  -H 'X-Riot-Entitlements-JWT: {entitlement token}' \
  -H 'Authorization: Bearer {auth token}'
```
