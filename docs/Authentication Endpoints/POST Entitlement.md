# POST Entitlement

> View on the website: <https://valdocs.prometheuz.me/endpoint/entitlement>

Get entitlement for remote requests with a token

Method: `POST`  
URL: `https://entitlements.auth.riotgames.com/api/token/v1`  

## Headers

- `Content-Type: application/json`
- `Authorization: Bearer {auth token}`

## Variables

- `{auth token}`: Obtained with the [Entitlements Token](https://valdocs.prometheuz.me/endpoint/entitlements-token) endpoint or Riot auth

## Example Request

```sh
curl -X POST 'https://entitlements.auth.riotgames.com/api/token/v1' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer {auth token}'
```

```ts
type EntitlementResponse = {
    entitlements_token: string;
};
```
