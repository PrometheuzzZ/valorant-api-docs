# Authentication Endpoints

| Endpoint | Description |
|---|---|
| [POST Auth Cookies](POST%20Auth%20Cookies.md) | Prepare cookies for auth request |
| [PUT Auth Request](PUT%20Auth%20Request.md) | Perform authorization request to get token |
| [PUT Multi-Factor Authentication](PUT%20Multi-Factor%20Authentication.md) | Submits a multi-factor authentication code for login |
| [GET Cookie Reauth](GET%20Cookie%20Reauth.md) | Get a new token using the cookies from a previous authorization request |
| [POST Entitlement](POST%20Entitlement.md) | Get entitlement for remote requests with a token |
| [GET Player Info](GET%20Player%20Info.md) | Get the PUUID and other info from a token |
| [PUT Riot Geo](PUT%20Riot%20Geo.md) | Get the region for a given ID token and auth token. The ID token and auth token can be obtained from [PUT Cookie Reauth] |
| [GET PAS Token](GET%20PAS%20Token.md) | Get a PAS token using the auth token. The PAS token is a JWT that contains the affinity for the XMPP server. |
| [GET Riot Client Config](GET%20Riot%20Client%20Config.md) | Gets the config file used by the Riot Client. This includes a ton of info, most of it undocumented. |
