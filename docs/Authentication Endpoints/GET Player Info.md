# GET Player Info

> View on the website: <https://valdocs.prometheuz.me/endpoint/player-info>

Get the PUUID and other info from a token

Method: `GET`  
URL: `https://auth.riotgames.com/userinfo`  

## Headers

- `Authorization: Bearer {auth token}`

## Variables

- `{auth token}`: Obtained with the [Entitlements Token](https://valdocs.prometheuz.me/endpoint/entitlements-token) endpoint or Riot auth

## Example Request

```sh
curl -X GET 'https://auth.riotgames.com/userinfo' \
  -H 'Authorization: Bearer {auth token}'
```
