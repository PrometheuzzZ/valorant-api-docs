# PUT Riot Geo

> View on the website: <https://valdocs.prometheuz.me/endpoint/riot-geo>

Get the region for a given ID token and auth token. The ID token and auth token can be obtained from [PUT Cookie Reauth](https://valdocs.prometheuz.me/endpoint/cookie-reauth)

Method: `PUT`  
URL: `https://riot-geo.pas.si.riotgames.com/pas/v1/product/valorant`  

## Headers

- `Authorization: Bearer {auth token}`

## Variables

- `{auth token}`: Obtained with the [Entitlements Token](https://valdocs.prometheuz.me/endpoint/entitlements-token) endpoint or Riot auth

## Example Request

```sh
curl -X PUT 'https://riot-geo.pas.si.riotgames.com/pas/v1/product/valorant' \
  -H 'Authorization: Bearer {auth token}' \
  -H 'Content-Type: application/json' \
  --data '{body}'
```

## Body

```ts
type RiotGeoBody = {
    /** The ID token */
    id_token: string;
};
```

## Response

```ts
type RiotGeoResponse = {
    token: string;
    /** The region IDs for PBE and live servers */
    affinities: {

    };
```
