# GET PAS Token

> View on the website: <https://valdocs.prometheuz.me/endpoint/pas-token>

Get a PAS token using the auth token. The PAS token is a JWT that contains the affinity for the XMPP server.

Method: `GET`  
URL: `https://riot-geo.pas.si.riotgames.com/pas/v1/service/chat`  

## Headers

- `Authorization: Bearer {auth token}`

## Variables

- `{auth token}`: Obtained with the [Entitlements Token](https://valdocs.prometheuz.me/endpoint/entitlements-token) endpoint or Riot auth

## Example Request

```sh
curl -X GET 'https://riot-geo.pas.si.riotgames.com/pas/v1/service/chat' \
  -H 'Authorization: Bearer {auth token}'
```
