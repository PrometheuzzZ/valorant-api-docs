# GET Player Region Index

> View on the website: <https://valdocs.prometheuz.me/endpoint/player-region-index>

Get a player's per-map rating ("Region Index") for a season. Each key of `regionData` is the map UUID (the `uuid` field on valorant-api.com, not the map path) and only maps the player has played in the season are included.

`matchHistory` is sorted from newest to oldest, the rating of the map after the newest match equals `values.regionIndex`. `bestMatch` is the entry of `matchHistory` with the highest `tempValueF`, and `topAgents` lists the agents played on the map.

Method: `GET`  
URL: `https://pd.{shard}.a.pvp.net/region-index/v1/players/{puuid}`  

## Headers

- `X-Riot-ClientPlatform: {client platform}`
- `X-Riot-ClientVersion: {client version}`
- `X-Riot-Entitlements-JWT: {entitlement token}`
- `Authorization: Bearer {auth token}`

## Variables

- `{shard}`: The shard the account was created on: `na`, `pbe`, `eu`, `ap` or `kr`
- `{puuid}`: A player's UUID
- `{client platform}`: See [Client Platform](https://valdocs.prometheuz.me/endpoint/player-mmr#client-platform)
- `{client version}`: See [Client Version](https://valdocs.prometheuz.me/endpoint/player-mmr#client-version)
- `{entitlement token}`: Obtained with the [Entitlements Token](https://valdocs.prometheuz.me/endpoint/entitlements-token) or [Entitlement](https://valdocs.prometheuz.me/endpoint/entitlement) endpoint
- `{auth token}`: Obtained with the [Entitlements Token](https://valdocs.prometheuz.me/endpoint/entitlements-token) endpoint or Riot auth

## Query Parameters

- `seasonID` (required): The season (act) to get the map ratings for

## Example Request

```sh
curl -X GET 'https://pd.{shard}.a.pvp.net/region-index/v1/players/{puuid}?seasonID={seasonID}' \
```
