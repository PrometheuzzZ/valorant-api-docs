# Mailbox

| Endpoint | Description |
|---|---|
| [GET Mailbox](GET%20Mailbox.md) | Get the in-game mail of a player, such as the notifications sent after a report is acted on. |
| [GET Mail](GET%20Mail.md) | Get a single mail by its ID. The response is the same object as the entries of the [GET Mailbox] endpoint, just not wrapped in an array. |
| [DELETE Delete Mail](DELETE%20Delete%20Mail.md) | Delete a single mail by its ID. The mail no longer shows up in the [GET Mailbox] endpoint afterwards. |
