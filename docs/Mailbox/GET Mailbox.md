# GET Mailbox

> View on the website: <https://valdocs.prometheuz.me/endpoint/mailbox>

Get the in-game mail of a player, such as the notifications sent after a report is acted on.

The `{cluster}` is the SGP cluster of the player's region and the `{puuid}` must be your own.

Method: `GET`  
URL: `https://{cluster}.pp.sgp.pvp.net/mailbox/v1/{puuid}/product/valorant`  

## Headers

- `Authorization: Bearer {auth token}`

## Variables

- `{cluster}`: SGP region cluster, e.g. `euc-prod` for EU
- `{puuid}`: Player UUID
- `{auth token}`: Obtained with the [Entitlements Token](https://valdocs.prometheuz.me/endpoint/entitlements-token) endpoint or Riot auth

## Query Parameters

- `count` (optional): Maximum number of mails to return, e.g. `100`
- `startIndex` (optional): Index of the first mail to return, used together with `count` for pagination
- `includedStates` (optional): Only return mails in this state. Can be repeated to include multiple states, e.g. `includedStates=NEW&includedStates=READ&includedStates=ACKNOWLEDGED`. Observed values: `NEW`, `READ`, `ACKNOWLEDGED`

## Example Request

```sh
curl -X GET 'https://{cluster}.pp.sgp.pvp.net/mailbox/v1/{puuid}/product/valorant?count={count}&startIndex={startIndex}&includedStates={includedStates}' \
  -H 'Authorization: Bearer {auth token}'
```
