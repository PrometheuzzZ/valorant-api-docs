# GET Mail

> View on the website: <https://valdocs.prometheuz.me/endpoint/mail>

Get a single mail by its ID. The response is the same object as the entries of the [GET Mailbox](https://valdocs.prometheuz.me/endpoint/mailbox) endpoint, just not wrapped in an array.

Method: `GET`  
URL: `https://{cluster}.pp.sgp.pvp.net/mailbox/v1/{puuid}/mail/{mail id}`  

## Headers

- `Authorization: Bearer {auth token}`

## Variables

- `{cluster}`: SGP region cluster, e.g. `euc-prod` for EU
- `{puuid}`: Player UUID
- `{mail id}`: The ID of the mail, obtained from the [GET Mailbox](https://valdocs.prometheuz.me/endpoint/mailbox) endpoint
- `{auth token}`: Obtained with the [Entitlements Token](https://valdocs.prometheuz.me/endpoint/entitlements-token) endpoint or Riot auth

## Example Request

```sh
curl -X GET 'https://{cluster}.pp.sgp.pvp.net/mailbox/v1/{puuid}/mail/{mail id}' \
  -H 'Authorization: Bearer {auth token}'
```

## Response

```ts
type MailResponse = {
    /** Mail ID */
    mailId: string;
    /** The player the mail was sent to */
    puuid: string;

    message: string;
    /** e.g. "valorant" */
    product: string;
    region: string | null;

    tags: string[];

    mailType: string;

    state: string;
    /** Milliseconds since epoch */
    createdAt: number;
};
```
