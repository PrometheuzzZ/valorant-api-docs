# POST Send Friend Request

> View on the website: <https://valdocs.prometheuz.me/endpoint/send-friend-request>

Sends a friend request to a player. Can be used in conjunction with [GET Friend Requests](https://valdocs.prometheuz.me/endpoint/friend-requests) and [DELETE Remove Friend Request](https://valdocs.prometheuz.me/endpoint/remove-friend-request) to determine a player's PUUID from their game name.

Method: `POST`  
URL: `https://127.0.0.1:{port}/chat/v4/friendrequests`  

## Headers

- `Authorization: Basic {base64 encoded "riot:{lockfile password}"}`

## Variables

- `{port}`: The port from the Riot Client lockfile (`%LocalAppData%\Riot Games\Riot Client\Config\lockfile`)
- `{base64 encoded "riot:{lockfile password}`

## Example Request

```sh
curl -X POST 'https://127.0.0.1:{port}/chat/v4/friendrequests' \
  -k \
  -u 'riot:{lockfile password}' \
  -H 'Content-Type: application/json' \
  --data '{body}'
```

type SendFriendRequestBody = {
