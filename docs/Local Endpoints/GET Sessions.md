# GET Sessions

> View on the website: <https://valdocs.prometheuz.me/endpoint/sessions>

Gets info about the running Valorant process including start arguments
  Can be used to get shard, region, and puuid by parsing launch args.

Method: `GET`  
URL: `https://127.0.0.1:{port}/product-session/v1/external-sessions`  
Internal name: `RiotClientSession_FetchSessions`  

## Headers

- `Authorization: Basic {base64 encoded "riot:{lockfile password}"}`

## Variables

- `{port}`: The port from the Riot Client lockfile (`%LocalAppData%\Riot Games\Riot Client\Config\lockfile`)
- `{base64 encoded "riot:{lockfile password}`

## Example Request

```sh
curl -X GET 'https://127.0.0.1:{port}/product-session/v1/external-sessions' \
  -k \
  -u 'riot:{lockfile password}'
```
