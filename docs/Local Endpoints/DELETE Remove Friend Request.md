# DELETE Remove Friend Request

> View on the website: <https://valdocs.prometheuz.me/endpoint/remove-friend-request>

Removes an outgoing friend request

Method: `DELETE`  
URL: `https://127.0.0.1:{port}/chat/v4/friendrequests`  

## Headers

- `Authorization: Basic {base64 encoded "riot:{lockfile password}"}`

## Variables

- `{port}`: The port from the Riot Client lockfile (`%LocalAppData%\Riot Games\Riot Client\Config\lockfile`)
- `{base64 encoded "riot:{lockfile password}`

## Example Request

```sh
curl -X DELETE 'https://127.0.0.1:{port}/chat/v4/friendrequests' \
  -k \
  -u 'riot:{lockfile password}' \
  -H 'Content-Type: application/json' \
  --data '{body}'
```
