# GET RSO User Info

> View on the website: <https://valdocs.prometheuz.me/endpoint/rso-user-info>

Get RSO user info

Method: `GET`  
URL: `https://127.0.0.1:{port}/rso-auth/v1/authorization/userinfo`  

## Headers

- `Authorization: Basic {base64 encoded "riot:{lockfile password}"}`

## Variables

- `{port}`: The port from the Riot Client lockfile (`%LocalAppData%\Riot Games\Riot Client\Config\lockfile`)
- `{base64 encoded "riot:{lockfile password}`

## Example Request

```sh
curl -X GET 'https://127.0.0.1:{port}/rso-auth/v1/authorization/userinfo' \
  -k \
  -u 'riot:{lockfile password}'
```

```ts
type RSOUserInfoResponse = {
    userInfo: string;
};
```
