# GET Presence

> View on the website: <https://valdocs.prometheuz.me/endpoint/presence>

Get a list of online friends and their activity
  If the player is playing Valorant, `private` is a base64-encoded JSON string that contains useful information such as party and in-progress game score.

Method: `GET`  
URL: `https://127.0.0.1:{port}/chat/v4/presences`  

## Headers

- `Authorization: Basic {base64 encoded "riot:{lockfile password}"}`

## Variables

- `{port}`: The port from the Riot Client lockfile (`%LocalAppData%\Riot Games\Riot Client\Config\lockfile`)
- `{base64 encoded "riot:{lockfile password}`

## Example Request

```sh
curl -X GET 'https://127.0.0.1:{port}/chat/v4/presences' \
  -k \
  -u 'riot:{lockfile password}'
```
