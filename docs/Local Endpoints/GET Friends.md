# GET Friends

> View on the website: <https://valdocs.prometheuz.me/endpoint/friends>

Get a list of friends

Method: `GET`  
URL: `https://127.0.0.1:{port}/chat/v4/friends`  

## Headers

- `Authorization: Basic {base64 encoded "riot:{lockfile password}"}`

## Variables

- `{port}`: The port from the Riot Client lockfile (`%LocalAppData%\Riot Games\Riot Client\Config\lockfile`)
- `{base64 encoded "riot:{lockfile password}`

## Example Request

```sh
curl -X GET 'https://127.0.0.1:{port}/chat/v4/friends' \
  -k \
  -u 'riot:{lockfile password}'
```
