# GET Entitlements Token

> View on the website: <https://valdocs.prometheuz.me/endpoint/entitlements-token>

Gets both the token and entitlement for API usage
`accessToken` is used as the token and `token` is used as the entitlement.

Method: `GET`  
URL: `https://127.0.0.1:{port}/entitlements/v1/token`  

## Headers

- `Authorization: Basic {base64 encoded "riot:{lockfile password}"}`

## Variables

- `{port}`: The port from the Riot Client lockfile (`%LocalAppData%\Riot Games\Riot Client\Config\lockfile`)
- `{base64 encoded "riot:{lockfile password}`

## Example Request

```sh
curl -X GET 'https://127.0.0.1:{port}/entitlements/v1/token' \
  -k \
  -u 'riot:{lockfile password}'
```

## Response

```ts
type EntitlementsTokenResponse = {
    /** Used as the token in requests */
    accessToken: string;
    entitlements: unknown[];
    issuer: string;
    /** Player UUID */
    subject: string;
    /** Used as the entitlement in requests */
    token: string;
};
```
