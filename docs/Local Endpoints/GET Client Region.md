# GET Client Region

> View on the website: <https://valdocs.prometheuz.me/endpoint/client-region>

Gets info about the region and locale from the Riot client

Method: `GET`  
URL: `https://127.0.0.1:{port}/riotclient/region-locale`  

## Headers

- `Authorization: Basic {base64 encoded "riot:{lockfile password}"}`

## Variables

- `{port}`: The port from the Riot Client lockfile (`%LocalAppData%\Riot Games\Riot Client\Config\lockfile`)
- `{base64 encoded "riot:{lockfile password}`

## Example Request

```sh
curl -X GET 'https://127.0.0.1:{port}/riotclient/region-locale' \
  -k \
  -u 'riot:{lockfile password}'
```

## Response

```ts
type ClientRegionResponse = {
    locale: string;
    region: string;
    webLanguage: string;
    webRegion: string;
};
```
