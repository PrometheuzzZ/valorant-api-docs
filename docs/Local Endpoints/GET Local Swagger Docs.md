# GET Local Swagger Docs

> View on the website: <https://valdocs.prometheuz.me/endpoint/local-swagger-docs>

Fetches json Swagger docs for local endpoints. Can be imported into Swagger or Insomnia.

Method: `GET`  
URL: `https://127.0.0.1:{port}/swagger/v3/openapi.json`  

## Headers

- `Authorization: Basic {base64 encoded "riot:{lockfile password}"}`

## Variables

- `{port}`: The port from the Riot Client lockfile (`%LocalAppData%\Riot Games\Riot Client\Config\lockfile`)
- `{base64 encoded "riot:{lockfile password}`

## Example Request

```sh
curl -X GET 'https://127.0.0.1:{port}/swagger/v3/openapi.json' \
  -k \
  -u 'riot:{lockfile password}'
```
