# GET Local Help

> View on the website: <https://valdocs.prometheuz.me/endpoint/local-help>

Get help for the local client

Method: `GET`  
URL: `https://127.0.0.1:{port}/help`  

## Headers

- `Authorization: Basic {base64 encoded "riot:{lockfile password}"}`

## Variables

- `{port}`: The port from the Riot Client lockfile (`%LocalAppData%\Riot Games\Riot Client\Config\lockfile`)
- `{base64 encoded "riot:{lockfile password}`

## Example Request

```sh
curl -X GET 'https://127.0.0.1:{port}/help' \
  -k \
  -u 'riot:{lockfile password}'
```
