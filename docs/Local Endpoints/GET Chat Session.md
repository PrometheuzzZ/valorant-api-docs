# GET Chat Session

> View on the website: <https://valdocs.prometheuz.me/endpoint/chat-session>

Get the current session including player name and PUUID

Method: `GET`  
URL: `https://127.0.0.1:{port}/chat/v1/session`  

## Headers

- `Authorization: Basic {base64 encoded "riot:{lockfile password}"}`

## Variables

- `{port}`: The port from the Riot Client lockfile (`%LocalAppData%\Riot Games\Riot Client\Config\lockfile`)
- `{base64 encoded "riot:{lockfile password}`

## Example Request

```sh
curl -X GET 'https://127.0.0.1:{port}/chat/v1/session' \
  -k \
  -u 'riot:{lockfile password}'
```
